# BL Melody Font Directory

Place your BL Melody font files in this folder.
Supported file names and formats:
- BL-Melody.woff2 (Recommended)
- BL-Melody.woff
- BL-Melody.ttf
- BL-Melody.otf
- BLMelody.woff2 / BLMelody.ttf

The application's centralized @font-face definition in `pub-exchange-tokens.css` is pre-configured to automatically load these font files with full font-weight coverage (100 to 900) across all views, kiosks, and dashboards.
